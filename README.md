# Ride Connect

Ride Connect は、一般ドライバー同士がマッチングして車のシェア・予約を行える Laravel 製のウェブアプリケーションです。プロフィールを登録したオーナーは保有車両を掲載でき、利用者は希望条件に合う車を検索してオンライントークや予約手続きまで進められます。

## 主な機能
- プロフィール作成：住所・運転免許区分・運転頻度などを登録し、乗る側／貸す側の信頼性を担保
- 車両登録：車種・年式・燃料タイプ・注意事項など詳細情報を掲載し公開ステータスを管理
- 予約フロー：借り手が申請すると、オーナー側の承認・日程調整・メッセージのやり取り・貸出完了確認まで一連の流れをサポート
- お気に入り機能：気になる車両を保存し、後から一覧で再確認
- 地域データ連携：都道府県・市区町村のマスターデータを保持し、地域に合わせた検索・表示を実現

## 技術スタック
- Backend: Laravel 10 / PHP 8
- Frontend: Blade, Tailwind CSS, Vite
- Database: MySQL (ローカル動作はSQLiteにも対応)
- 認証基盤: Laravel Breeze + フォーム認証

## セットアップ
1. `composer install` と `npm install` を実行
2. `.env` を `.env.example` からコピーし、DB接続・メール送信などの環境変数を設定
3. アプリケーションキーを発行：`php artisan key:generate`
4. マイグレーションとシーディング：`php artisan migrate --seed`
5. 開発サーバー起動：`php artisan serve` と `npm run dev`
